# Google Play & F-Droid Store Metadata

This directory stores the official store listing copy and metadata for ALauncher in the industry-standard Fastlane / F-Droid layout.

## Directory Structure
```
fastlane/metadata/android/
└── en-US/
    ├── title.txt               # App title (max 30 characters)
    ├── short_description.txt   # Short description / tagline (max 80 characters)
    └── full_description.txt    # Full store description (max 4000 characters)
```
